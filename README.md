# DQ250Studio

Приложение для просмотра, сравнения и редактирования поддерживаемых калибровок DQ250 и анализа логов. Работает на Windows и Android. AI необязателен.

[Скачать DQ250Studio](https://github.com/Belka1243/DQ250Studio-releases/releases)

- **Windows x64.** `clean_x64.exe` для новой установки, `update_x64.exe` для существующей совместимой установки 0.20.1-betaAI. Прямое обновление HF1 не поддерживается. Установщики без цифровой подписи издателя. Версия 0.22.0-betaAI работает по 28 февраля 2027 года включительно.
- **Android 10+.** Один подписанный APK для 64-битных ARM и x86. Календарного срока действия нет.
- **Документация.** Руководства, известные ограничения и лицензионные соглашения входят в архив документации в релизе. Контрольные суммы файлов находятся рядом.

Это закрытый продукт. Условия использования приведены в лицензионном соглашении соответствующей платформы. Готовность экспортированного BIN к записи на TCU нужно проверять отдельно. Если сообщаете об ошибке, укажите платформу, версию и шаги воспроизведения. Для начала достаточно описания и диагностических сведений без персональных данных.
